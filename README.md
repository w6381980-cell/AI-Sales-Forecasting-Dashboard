# 🚀 AI-Powered Sales Forecasting Dashboard

## 📌 Overview
This project is an end-to-end data analytics system that generates synthetic retail data, performs analysis, predicts future sales, and visualizes insights through an interactive Power BI dashboard.

---

## 🔥 Features
- 📊 Automated Data Generation (Python)
- 🧹 Data Cleaning & Transformation
- 🛢️ SQL Database Integration
- 🔮 Time Series Forecasting
- 📈 Interactive Power BI Dashboard
- 📄 Automated Excel & PDF Reports
- 🧠 Auto-generated Business Insights

---

## 🛠 Tech Stack
- Python (Pandas, NumPy, Matplotlib, Statsmodels)
- SQL (SQLite)
- Power BI

---

## 📊 Dashboard Insights
- Total Revenue, Profit & Orders
- Monthly Sales Trends
- Region-wise Performance
- Product-wise Analysis
- Forecasted Sales vs Actual

## ⚙️ How to Run
1. Clone the repository  
2. Install dependencies:

pip install pandas matplotlib statsmodels openpyxl reportlab

3. Run the pipeline:

python python/main.py
